# S3Workbench Homebrew tap

Homebrew distribution for [S3Workbench](https://github.com/romainfrezier/S3Workbench),
a native browser for S3-compatible storage.

The initial cask is being prepared in
[S3Workbench #8](https://github.com/romainfrezier/S3Workbench/issues/8).
Installation and upgrade validation must pass before the tap is announced as ready.

Use the [published DMG](https://github.com/romainfrezier/S3Workbench/releases/latest)
while that work is in progress.
